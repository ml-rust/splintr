# splintr-vocab-glm

GLM-4 and GLM-4.5.

Data only — the packed bytes of one vocabulary family, with nothing that interprets them. Use [`splintr`](https://crates.io/crates/splintr) with its `vocab-glm` feature; that is what re-exports these constants and can load them.

## Provenance

Extracted from `zai-org/GLM-4.5` on HuggingFace. The vocabulary is upstream's, not splintr's, and keeps upstream's licence — MIT, as the model repository declares. See `LICENSE`, which also records that upstream publishes no notice file of its own.
