# splintr-vocab-o200k

OpenAI o200k_base — GPT-4o, and the ranks gpt-oss layers its harmony specials over.

Data only — the packed bytes of one vocabulary family, with nothing that interprets them. Use [`splintr`](https://crates.io/crates/splintr) with its `vocab-o200k` feature; that is what re-exports these constants and can load them.

## Provenance

Extracted from OpenAI, `https://openaipublic.blob.core.windows.net/encodings/o200k_base.tiktoken`. The vocabulary is upstream's, not splintr's, and keeps upstream's licence — see `LICENSE`.
