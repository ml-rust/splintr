# splintr-vocab-deepseek

DeepSeek V3 and R1.

Data only — the packed bytes of one vocabulary family, with nothing that interprets them. Use [`splintr`](https://crates.io/crates/splintr) with its `vocab-deepseek` feature; that is what re-exports these constants and can load them.

## Provenance

Extracted from `deepseek-ai/DeepSeek-V3` on HuggingFace. The vocabulary is upstream's, not splintr's, and keeps upstream's licence — see `LICENSE`.
