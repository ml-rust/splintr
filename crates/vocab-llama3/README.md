# splintr-vocab-llama3

Meta Llama 3, 3.1, 3.2 and 3.3.

Data only — the packed bytes of one vocabulary family, with nothing that interprets them. Use [`splintr`](https://crates.io/crates/splintr) with its `vocab-llama3` feature; that is what re-exports these constants and can load them.

## Provenance

Extracted from `meta-llama/Llama-3.1` on HuggingFace. The vocabulary is upstream's, not splintr's, and keeps upstream's licence — see `LICENSE`.
